**Настройка перед первым запуском:**

1. Найдите реальный путь к профилю WindTerm. Проще всего:
   ```bash
   cat /путь/к/WindTerm/profiles.config
   ```
   или в самой программе: Session → Preferences → About → Profile Directory. Часто это `~/.wind`, но иногда `~/.config/.wind` — проверьте у себя и поправьте `LIVE_PROFILE_DIR` в скрипте.

2. Поправьте `WINDTERM_EXE` — путь к исполняемому файлу WindTerm.

3. Дайте скрипту права на выполнение (уже сделано, но на будущее):
   ```bash
   chmod +x windterm_env.sh
   ```

**Использование:**

```bash
# Сохранить текущее состояние окон/сессий как "project-a"
./windterm_env.sh save project-a

# Переключиться на этот набор и запустить WindTerm с ним
./windterm_env.sh load project-a

# Посмотреть список сохранённых наборов
./windterm_env.sh list
```

Логика та же, что и в PowerShell-версии: скрипт закрывает запущенный WindTerm (иначе он может переписать файлы профиля при выходе поверх вашего копирования), затем зеркалирует папку через `rsync -a --delete` — так что переключение между наборами получается чистым, без остатков от других проектов.
